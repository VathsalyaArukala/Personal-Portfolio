# Personal Portfolio Website

## About the Project

This is my personal portfolio website, created to introduce myself, share my technical skills, showcase my projects, and provide my educational background and contact information.

The website is designed with a clean layout and responsive design to provide a good viewing experience across different screen sizes.

## Technologies Used

- HTML5
- CSS3

## Features

- Home section with a personal introduction
- About Me section
- Technical Skills section
- Projects section with GitHub links
- Educational details
- Contact information
- Responsive layout for different devices
- favicon and profile image

FRAUD DETECTION FOR ONLINE TRANSACTIONS

Fraud Detection for Online Transactions is a machine learning-based web application that addresses the problem of identifying fraudulent online transactions. It analyzes transaction details such as sender ID, receiver ID, transaction amount, transaction type, and fraud history to detect suspicious activities. The system uses three separate machine learning models to predict sender fraud, receiver fraud, and overall transaction fraud. Its key features include real-time fraud prediction, fraud probability display, and a simple, user-friendly Flask web interface that helps users identify potentially fraudulent transactions.

Technologies Used:

  • Python - Core programming language.
  • Flask - Backend web framework.
  • HTML5 - Web page structure.
  • CSS3 - Frontend styling.
  • NumPy - Numerical operations and data processing.
  • Joblib - Saving and loading trained machine learning models.
  • Matplotlib - Visualizing model performance and evaluation metrics.
  • Machine Learning - Fraud prediction and classification.

AUTOMATIC TIMETABLE GENERATOR

The Automatic College Timetable Generator is a web-based application that solves the problem of manually creating and managing college timetables, which can be time-consuming and may lead to scheduling conflicts. The system automates timetable generation based on branches, academic years, and semesters. Its key features include automated timetable generation, branch-wise and year-wise scheduling, conflict-free scheduling, efficient management of subjects and teachers, and an easy-to-use interface for viewing generated timetables. It is developed using Python, Flask, HTML5 and CSS3.

Technologies Used:

  • Backend: Python,Flask
  • Frontend: HTML5,CSS3
  • Development Environment: VS Code
